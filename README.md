# Ember Outpost 〜雪原のたき火拠点〜

スマホのブラウザで遊べる、雪原サバイバル系の「アイドルアーケード」ミニゲームです。
白熊を倒して肉を集め、焚き火で焼いて生存者に配り、稼いだコインで仲間を雇って拠点を少しずつ自動化していきます。
1回目のクリアまで約2〜3分、続きの「もっと育てる」まで遊んで合計5〜6分ほど。

## 遊び方

- **移動**: 画面のどこをなぞっても出る仮想スティック（PC は WASD / 矢印キー）
- **熊**: 近くの熊を自動で撃つ。熊は殴る前に赤く光るので避けられる。倒れても焚き火の前で復活（ゲームオーバーなし）
- **肉**: 熊は肉を2〜3個落とす。近くを通るだけで拾い、背中に最大30個積み上がる
- **焼く・売る**: 生肉を焚き火に置く → 焼き肉をカウンターへ → 並んだ生存者に配るとコイン
- **建設マス**: マスの上で立ち止まるとコインが吸い込まれ、満額で完成。画面の矢印が次の行き先を教えてくれる

## 進み方

**前半（自動化 n/7）** — レジ係 → 大砲 Lv1 → 運搬係（最大3人）→ 大砲 Lv2 → 狩り仲間 → 大砲 Lv3 → 拠点の拡張
拠点の拡張で柵が広がり「拠点が自分で回り始めた！」でクリア。

**後半「もっと育てる」（拠点完成 n/5）** — 大かまど → 2台目のカウンター → レジ係の強化 → 2人目の狩り仲間 → 大倉庫
任意で 運搬係の増員（最大5人）・大砲 Lv4 / Lv5・でかリュック（積載50 → 80）。
大倉庫で「拠点完成！」。画面上部の「+○/秒」で稼ぎの速さが上がっていくのが見えます。

## 特徴

- スマホ縦画面・片手操作に最適化（スクロール／ピンチ拡大／長押し選択を抑止、ノッチ対応）
- 大砲は Lv1〜5 で段階的に強化。見た目もレベルごとに変化
- ダメージ数字、弧を描いて飛ぶ肉とコイン、仲間の登場演出、紙吹雪などの演出
- 効果音は WebAudio で合成（外部ファイルなし）。画面上部のボタンで消音
- 画像アセットなし。すべて Canvas 2D の図形で描画

## 技術

Vite + TypeScript + HTML5 Canvas（ゲームエンジン不使用）。静的サイトとして Vercel で公開。

```bash
npm install
npm run dev     # http://localhost:5173 （--host 付きなので同じ Wi-Fi のスマホからも開ける）
npm run build   # dist/ に出力
```

`?debug=1` を付けるとコイン +50 ボタンが出ます。

## 開発の進め方

`.product/spec.md` の仕様をスプリント単位で、実装担当と評価担当（実際にブラウザで遊んで合否判定）のエージェントに分けて開発しました。各スプリントの自己評価と評価結果は `.product/sprints/` にあります。

※ ゲーム性はスマホゲームの広告ミニゲームを参考にしたオリジナル作品で、既存タイトルの素材・名称は使用していません。
