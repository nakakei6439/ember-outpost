# スプリント 01 自己評価（attempt 1）
全受け入れ条件（追加分含む）を headless Chrome(390x844, touch emulation) + キーボード自動操縦で確認。
- 熊撃破→肉2個→背中に積み上がり(MAX表示)→投入マス→焼き肉→受取マス→配給→札束→回収で所持金=去った人数x5 を確認（例: 5人で25）。
- 熊反撃: 被弾で HP 減少・ダメージ数字・画面揺れ。HP 0 で気絶→2秒後に焚き火横で全回復（一時的に熊ダメージを100にして確認済み、元に戻した）。焚き火近くで回復を確認。
- 仮想スティックはポインタイベント実装。実機タッチでのスクロール/ズーム抑止は meta/CSS/イベント抑止で対応したが、Playwrightでのタッチドラッグ実測はしていない（キー操作で検証）。
## 動かし方
npm run dev (http://localhost:5173) / npm run build -> dist/。window.__ember.snapshot() で状態取得可。
